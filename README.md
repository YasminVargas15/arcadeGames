# 🎮 ArcadeGames

ArcadeGames é uma plataforma de mini jogos desenvolvida com HTML, CSS e JavaScript, criada para unir diversão, design moderno e interatividade em um único projeto. O site possui interface inspirada em jogos arcade, com efeitos visuais neon, animações suaves e jogos totalmente funcionais.

---

# 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---

# 🎯 Objetivo do Projeto

O objetivo do projeto foi desenvolver uma plataforma moderna de mini jogos para praticar:

- lógica de programação;
- manipulação do DOM;
- animações;
- responsividade;
- organização de código;
- desenvolvimento front-end.

---

# 🎮 Jogos Disponíveis

## ✊ Jokenpô
Clássico Pedra, Papel e Tesoura contra a máquina.

### Recursos:
- inteligência artificial simples;
- histórico das partidas;
- sequência de vitórias;
- estatísticas em tempo real;
- animações de batalha.

---

## 🪙 Cara ou Coroa
Jogo baseado em probabilidade e sorte.

### Recursos:
- moeda animada;
- precisão de acertos;
- histórico;
- sequência de vitórias;
- feedback visual.

---

## 🎲 Dados
Simulação de lançamento de dados.

### Recursos:
- modo simples;
- modo com múltiplos dados;
- histórico das rodadas;
- taxa de vitória;
- placar em tempo real.
